## OneKey PIN 码的安全性

可以放心，**OneKey 的 PIN 码设计是安全的**。

很多用户会担心，如果 PIN 码没有设置得特别复杂，设备是否会更容易被破解。实际上，硬件钱包的安全性并不只取决于 PIN 码长度，而是取决于 **设备本身的安全机制**、**错误输入限制**，以及 **设备是否由用户妥善保管**。

PIN 码并不是单独发挥作用的。它是硬件钱包整体安全设计中的一部分，用来在设备被短暂接触或意外落入他人手中时，提供第一层访问保护。

## 安全性与易用性的平衡

硬件钱包的设计需要在 **安全性和易用性之间取得平衡**。

如果 PIN 码设置过于复杂，用户在日常使用中的输入成本会明显增加，也更容易影响实际体验。对于硬件钱包来说，一个**足够安全、同时方便正确使用**的方案，通常比“理论上更强、但使用负担很重”的方案更适合长期使用。

安全设计的目标，不只是提高理论门槛，更重要的是让用户能够长期、稳定、正确地使用它。

## PIN 码被暴力碰撞破解的可能性很低

正常情况下，**PIN 码被暴力碰撞破解的概率极低**。

如果攻击者想通过不断尝试来猜中 PIN，首先必须拿到你的设备；同时，PIN 码的尝试次数并不是无限制的，设备本身也具备相应的安全保护机制。

因此，在真实场景里，风险的重点通常不是“别人随机蒙中 PIN”，而是：

- 设备被他人接触
- PIN 码被泄露
- 在不安全环境下输入 PIN

只要设备保管得当、PIN 码没有泄露，这类攻击成功的可能性是非常低的。

## 正确的使用习惯可以进一步提高安全性

### 1. 将设备保存在安全、不被他人触碰的地方

请尽量将设备放在只有你自己能接触的位置，避免他人长时间接触设备。

### 2. 不要将 PIN 码告诉任何人

PIN 码应仅由你自己掌握，不要通过聊天、截图、拍照或其他方式保存和分享。

### 3. 输入 PIN 时注意周围环境

在公共场所或有他人在场时，注意遮挡输入过程，避免被旁观。

## 总结

OneKey 的 PIN 码机制是在 **安全性和易用性之间做出的平衡设计**。PIN 码的作用，不是脱离设备安全机制去单独对抗无限次暴力破解，而是与设备保护机制、错误限制和用户的保管习惯共同发挥作用。

只要你妥善保管设备、不泄露 PIN 码，并在安全环境下使用，PIN 码被碰撞破解的概率是极低的，可以放心使用。
