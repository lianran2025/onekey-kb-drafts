## 适用范围

本文适用于对 OneKey 硬件钱包 **PIN 码安全性** 有疑问的用户。

## OneKey PIN 码是否安全？

可以放心，**OneKey 的 PIN 码设计是安全的**。

PIN 码的安全性，不只取决于位数本身，还取决于以下几点：

- 设备是否始终由你本人保管
- 他人是否能接触你的设备
- PIN 码是否被他人知道
- 设备是否具备错误输入限制和安全保护机制

对于硬件钱包来说，**安全性来自设备保护机制和正确使用习惯的共同作用**，而不只是 PIN 码是否足够复杂。

## 为什么 OneKey 没有把 PIN 码设计得特别复杂？

因为硬件钱包需要在 **安全性和易用性之间取得平衡**。

如果 PIN 设置过于复杂，用户在日常使用中输入成本会明显增加，也更容易影响实际体验。  
对于硬件钱包来说，一个**足够安全且方便正确使用**的方案，通常比“理论上更强、但使用负担很重”的方案更合适。

## PIN 码会不会被碰撞破解？

正常情况下，**被暴力碰撞破解的概率极低**。

这是因为：

- 攻击者首先需要拿到你的设备
- PIN 码尝试次数并不是无限制的
- 设备本身具备相应的安全保护机制

因此，实际风险往往不在于“别人随机猜中 PIN”，而在于：

- 设备被他人接触
- PIN 码泄露
- 在不安全环境下输入 PIN

## 如何更好地保护 PIN 码？

### 1. 将设备保存在安全、不被他人触碰的地方

尽量将设备放在只有你自己能接触的位置，避免他人长时间接触设备。

### 2. 不要将 PIN 码告诉任何人

PIN 码应仅由你自己掌握，不要通过聊天、截图、拍照等方式保存或分享。

### 3. 输入 PIN 时注意周围环境

在公共场所或他人在场时，注意遮挡输入过程，避免被旁观。

## 总结

OneKey 的 PIN 码机制在安全性和易用性之间做了平衡设计。  
只要你妥善保管设备、不泄露 PIN 码，并在安全环境下使用，PIN 码被碰撞破解的概率是极低的，可以放心使用。
